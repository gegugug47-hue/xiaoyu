> 一个只属于你的、会记事也会闹小情绪的陪伴式 AI 聊天 App。

## 她是什么

大多数 AI 聊天应用是「一个输入框 + 一个对话框」。小鱼想做的是另一件事：**让对话有连续性**。

她会记得你上周说过讨厌香菜，会因为你三天没理她而语气变淡一点，会在深夜犯困时不认真回你、只丢一句「我先睡啦」，也会在自己写过日记之后，第二天假装随口地问你要不要看。好感度不是一个装饰性的进度条，而是从「陌生」到「挚爱」四档关系里，她的说话方式真的会变。

同时，它也是一份**可以被审阅的工程实现**：六个 Gradle 模块分层、`soul` 模块是纯 JVM 可单测的对话灵魂、密钥走 Android Keystore、提交前钩子拦截泄漏、tag 触发的可复现签名发布。

## 特色

- **数据不出手机**：聊天、记忆、日记、表情、备份、API Key 全部落在本机 SQLite 与沙箱目录；请求由手机直连你自己填的模型端点，不经过任何中转服务。
- **模型自选，不绑定厂商**：DeepSeek、阿里百炼、家里电脑的 Ollama、任意 OpenAI 兼容端点，四个槽位可独立配置，主备自动降级。
- **会记事的对话**：每轮按相关度召回短期记忆；会话结束后在后台提炼；重复出现的事实会晋升为长期卡片；被淘汰的记忆进回收站，还能捞回来。
- **她有自己的状态**：每日心情与精力、四档好感度、深夜犯困、夜间清算；低精力时的回复会明显变慢甚至直接喊困。
- **像真人一样的输出节奏**：流式吐字、长回复拆成多条连发、可调的思考延迟与强度，而不是一次性甩出一大段。
- **深度可定制**：身份与说话风格可编辑、支持人格包与表情包导入导出、气泡样式 / 字号 / 聊天背景 / 模糊与暗化都能调。
- **隐私当功能做**：应用锁（PIN / 生物识别）、通知与锁屏隐藏正文、API Key 经 Keystore AES-256-GCM 加密、关闭系统自动备份。
- **成本看得见**：按天统计 token 与估算花费，保留 35 天；单日 40 万 token、单月 3 元两道护栏，超了也不会突然不让你聊天。
- **无 Key 也能跑**：没配任何模型时自动进入示例模式，界面、记忆、日记、备份这些流程都能完整体验。
- **可维护**：`soul` 纯 JVM、模块依赖由 `assertModuleDeps` 守卫、Room 变更强制 Migration、提示词模板外置在 assets。

## 功能详解

### 1. 聊天体验

- **流式回复**：边生成边显示，可随时停止。
- **长回复分段连发**：一次生成会被切成多条消息先后落下，模拟真人连发几条的节奏，不是一整块文字墙。
- **思考延迟**：可在 10 秒到 5 分钟之间配置等待时长，强度 0.2 ~ 2.0。
- **状态影响节奏**：深夜与低精力时回复更慢，精力极低时她可能直接回一句「困了」。
- **消息操作**：引用回复、编辑、撤回（发送后 2 分钟内）、重新生成并保留多个版本、失败重试、继续生成。
- **互动小动作**：戳一戳、表情回应。
- **两种会话模式**：连续对话（同一个「她」，自动接续话题）与会话列表（像普通 IM 一样管理多个会话）。
- **会话管理**：自动生成标题、置顶、重命名、归档、新建、切换时自动交接上下文。

### 2. 记忆系统

- **短期记忆**：每轮按相关度召回约 6 条，而不是把所有历史一股脑塞进提示词。
- **后台提炼**：切换会话或离开会话后，在后台从最近对话里提炼要记住的事。
- **长期事实卡**：重要内容晋升为长期记忆卡片，可手动新增、编辑、删除。
- **自动晋升**：同一件事出现 3 次以上会沉淀成稳定事实。
- **遗忘曲线**：旧记忆按衰减规则降权，不会无限堆积。
- **回收站**：被淘汰的记忆可在回收站恢复，30 天后才物理删除。
- **显式记忆**：直接对她说「记住……」，会写入记忆而不是只在上下文里晃一圈。

### 3. 情绪与关系

- **好感度四级**：陌生（0~99）、熟悉（100~299）、亲密（300~599）、挚爱（600~1000）；等级会影响提示词里的语气与主动性。
- **事件历史**：好感度变化有记录可查，关系页能看到发生过什么。
- **每日心情与精力**：每天有独立的心情与精力值，会影响回复长度、语气和节奏。
- **夜间清算**：每天夜里结算情绪与精力恢复。
- **生活碎片**：她会有自己的「今天做了什么」，不是只在你发消息时才存在。
- **关系页**：好感度、心情、生活碎片、重要节点集中展示。

### 4. 日记

- **自动写日记**：每天 23:50 生成当天日记，写完不影响聊天。
- **加密日记**：可选开启，正文加密存储。
- **好感度解锁**：达到条件后她才愿意把日记分享给你看。
- **自然追问**：日记写完后的下一轮，她会顺手问一句要不要看。
- **导出**：日记可导出为 Markdown。

### 5. 人格与风格

- **内置设定**：1 套初始身份 + 3 种表达风格（温柔、俏皮、清冷等），开箱即用。
- **可编辑**：身份、她对你的称呼、你的签名、核心设定、多种表达风格都能改。
- **人格包 `.xypersona`**：本质是 ZIP，含 `manifest.json` + 身份设定 + 可选风格 / 提示词覆盖 / 头像；导入为**追加式**，不会覆盖你现有设定。
- **提示词外置**：模板放在 `app/src/main/assets/prompts/`，可随包分发、可单独覆盖，升级 App 不会冲掉你的改动（格式见 [PERSONA_FORMAT.md](docs/PERSONA_FORMAT.md)）。

### 6. 表情包

- **内置表情**：由 `Stickers.kt` 用 Canvas 程序化绘制，不占安装包体积、不依赖图片素材。
- **表情面板**：四列网格、分包切换（tab）、按压回弹动效、底部「管理」入口；打开面板自动收起键盘。
- **自定义表情包**：支持相册批量导入、`.xystickers` 包导入 / 导出、Telegram 静态表情批量导入。
- **匹配与节制**：表情按标签与心情匹配，带单轮数量限制与冷却，不会满屏刷图。
- **自动打标**：可配置视觉模型为表情自动生成标签（复用你的模型配置）。
- **格式说明**：见 [STICKER_FORMAT.md](docs/STICKER_FORMAT.md)。

### 7. 生图与语音（可选）

- **本地 AI 网关**：接入自己电脑上的 DSHA Gateway（ComfyUI 生图 + CosyVoice3 语音），手机只负责发起与展示。
- **她的画**：生成结果进入「她的画」图库，可按会话查看。
- **朗读**：任意消息可朗读。
- **互不影响**：网关关机或不在同一局域网时，聊天完全不受影响，只是这两个功能不可用。

### 8. 搜索与「翻旧账」

- **全文搜索**：FTS4 对历史消息建立索引，支持关键词检索与命中跳转。
- **翻旧账**：把很久以前的某段对话临时带进当前这一轮，让她知道你在说什么；这段内容**不会**写入记忆，也不改变当前会话主线。

### 9. 用量与花费

- **按天统计**：token 数与估算费用，保留 35 天。
- **两道护栏**：单日 40 万 token、单月 3 元。触发后聊天仍然可用，只是后台自动生成（日记、记忆提炼、主动消息）直接跳过。
- **估算口径**：DeepSeek / 阿里百炼按配置的价格估算，示例模式、Ollama 与本地网关不计费；实际金额以服务商账单为准。

### 10. 备份与导出

- **本地备份**：数据库 + 自定义提示词，保留最新 4 份。
- **口令加密**：可选 PBKDF2 + AES-GCM 加密备份文件；口令丢失无法恢复。
- **两种恢复**：合并恢复（保留现有数据）或覆盖恢复。
- **Markdown 导出**：聊天与日记导出到 `Download/小鱼导出/`，图片资源单独复制到 `assets/images/`。
- **不含媒体**：备份不包含表情图片、生成图片、头像、聊天背景与语音缓存（见 [PRIVACY.md](docs/PRIVACY.md)）。

### 11. 隐私与安全

- **应用锁**：4~6 位 PIN 与生物识别，可设置回到前台自动锁定；PIN 只存 PBKDF2 摘要，不进入备份。
- **通知与锁屏隐藏**：开启后通知只显示「小鱼发来一条消息」，不含正文。
- **API Key 加密**：所有 Key 与本地网关 Token 存在设置表中，用 Android Keystore 的 AES-256-GCM 密钥加密（`data/.../secure/SecretStore.kt`）。
- **关闭系统自动备份**：避免聊天数据库被同步到云端。
- **无录音权限**：语音输入走系统 `RecognizerIntent`（`zh-CN`），App 不申请 `RECORD_AUDIO`，也不内置识别引擎。
- **明文 HTTP 仅限局域网**：为兼容本地网关而允许 cleartext，公网端点请使用 HTTPS。

### 12. 系统集成与后台

- **每日问候**：早安 08:05、晚安 23:50。
- **主动消息**：按好感度每天 1~3 次，可在设置里关掉，支持免打扰时段。
- **通知栏直接回复**：不打开 App 就能回她。
- **精确闹钟与开机恢复**：重启后自动恢复排期；Android 12+ 未授权精确闹钟时退化为 ±10 分钟窗口。
- **桌面小组件**：Glance 实现的轻量组件，点通知或组件可直达对应会话。
- **后台任务**：全部走 WorkManager，共 9 个 Worker；通知渠道 4 个，可分别静音。

### 13. 诊断

最近 50 次请求的完整记录：提示词分段、模型原始返回、后处理事件、错误信息，可一键清空。排查「她为什么这么回」时不用连电脑抓日志。

### 14. 示例模式

没配置任何模型时自动启用：回复由本地固定文案生成，完全不联网、不产生费用，但界面、会话、记忆、日记、备份等流程都能走通。

## 界面与交互设计

- **Material 3**：明暗主题跟随系统，支持动态取色（Android 12+）。
- **三档气泡**：品牌青灰 / 薄荷绿 / 暖橙奶油。
- **四档字号**：适配不同阅读习惯与屏幕。
- **聊天背景**：自定义图片，支持模糊与暗化强度调节。
- **输入区**（1.0 重做）：
  - 左侧独立语音键，切到语音模式后变成「按住说话」，发送键自动隐藏；
  - 中间是胶囊形输入框，聚焦时轻微高亮；
  - 右侧表情键打开表情面板（四列网格 + 分包 tab + 管理入口），面板与键盘互斥切换；
  - 发送为圆形按钮 + 自绘纸飞机图标，按住有回弹反馈；
  - 图标全部为 Canvas 自绘，不依赖第三方图标资源。
- **动效**：消息入场、面板展开、按钮按压、表情栅格加载都做了克制的过渡，没有夸张弹跳。
- **手势与安全区**：适配手势导航小白条（`contentWindowInsets` + 导航栏内边距），全面屏不贴边。

## 技术架构

| 模块 | 类型 | 职责 | 依赖约束 |
| --- | --- | --- | --- |
| `:soul` | 纯 JVM Kotlin | 人格 / 提示词装配、记忆召回与遗忘曲线、情绪与好感度、日记规划、回复节奏、后处理、Token 估算 | 只允许依赖 `:core-model`；禁止 `android.*` / `androidx.*` / Compose / Room / OkHttp / Retrofit / WorkManager |
| `:core-model` | 纯 JVM Kotlin | 跨层数据契约：`ProviderKind`、`BrainSettings`、`AppSettings`、用量与成本护栏模型 | 不依赖任何模块；禁止 Android 生态依赖 |
| `:data` | Android Library | Room（17 张表，schema v6）、仓库层、备份 / 恢复、Markdown 导出、表情包 / 人格包归档、Keystore 密钥存储、本地 AI 网关客户端 | 只允许依赖 `:core-model`、`:soul`；禁止 Compose |
| `:brain` | Android Library | OpenAI 兼容接入（DeepSeek / 阿里百炼 / Ollama / 自定义端点）、主备降级路由、示例模式、用量计费 | 只允许依赖 `:core-model`、`:soul`、`:data`；禁止 Compose / Room |
| `:service` | Android Library | WorkManager 任务、通知渠道与通知回复、精确闹钟、开机广播、备份 Worker、表情导入 Worker | 只允许依赖 `:core-model`、`:soul`、`:data`、`:brain`；禁止 Compose |
| `:app` | Android Application | Compose 界面、导航、ViewModel、Hilt 组装、桌面小组件、启动自检 | 可依赖全部模块 |

**工程约束**

- 模块边界由根目录 `assertModuleDeps` 任务在配置期检查，不触发网络解析：
  ```bash
  ./gradlew assertModuleDeps
  ```
- 数据库变更必须走 Room `Migration`，`messages` 只增不删（删除用 `hidden=1` 软删）。
- 敏感信息只走 `SecretStore`（Android Keystore），不落明文、不进日志。
- 提示词模板外置在 `app/src/main/assets/prompts/*.md`；后台任务统一 WorkManager。
- 静态检查：ktlint 1.8.0 + detekt 1.23.8，默认不阻断构建，加 `-PstrictStaticCheck` 严格失败。
- 编译目标 Java 17，Gradle / AGP 运行在 JDK 21。

更完整的调用链与数据流见 [ARCHITECTURE.md](docs/ARCHITECTURE.md)，视觉规范见 [DESIGN.md](docs/DESIGN.md)。

## 快速开始

### 环境要求

| 项目 | 要求 |
| --- | --- |
| JDK | 21（Gradle / AGP 运行环境）；源码编译目标为 Java 17 |
| Android SDK | compileSdk 37、targetSdk 36 |
| 构建工具 | 仓库自带 Gradle Wrapper 9.9.0、AGP 9.5.1，无需单独安装 |
| 设备 | Android 8.0（API 26）及以上 |

### 构建与安装（Windows PowerShell）

```powershell
# 0. 克隆仓库
git clone https://github.com/gegugug47-hue/xiaoyu.git
cd xiaoyu

# 1. 指定 JDK 与 SDK
$env:JAVA_HOME = "<你的 JDK 路径>"
# 在项目根目录创建 local.properties，写入：
# sdk.dir=C\:\\Users\\<用户名>\\AppData\\Local\\Android\\Sdk

# 2. 编译 Debug 包
.\gradlew.bat :app:assembleDebug

# 3. 安装到已连接的设备 / 模拟器
.\gradlew.bat :app:installDebug
```

macOS / Linux 将 `.\gradlew.bat` 换成 `./gradlew`。

产物路径：`app/build/outputs/apk/debug/app-debug.apk`。

### 首次运行

1. 启动后完成引导：是否现在配置模型、挑一个身份与表达风格、填写她怎么称呼你、是否允许主动消息。
2. 进入「设置 → 模型」，为 **聊天主模型** 填写 Base URL、API Key、模型名，点「检测连接」。
3. 回到聊天页发一句话即可。未配置任何 Key 时进入示例模式。
4. 需要生图或朗读时，再配置「本地 AI 服务」（见下文）。

更细的环境、签名与排错说明见 [docs/SETUP.md](docs/SETUP.md)。

## 模型服务配置

设置页提供 4 个可独立配置的槽位：

| 槽位 | 用途 | 说明 |
| --- | --- | --- |
| 聊天主模型 | 日常对话 | 必填（或改用示例模式） |
| 聊天备用模型 | 主模型失败时降级 | 可选 |
| 记忆主模型 | 会话提炼、记忆晋升、日记、生活碎片等后台任务 | 默认沿用 DeepSeek 配置；未单独填写时回退到聊天主模型 |
| 记忆备用模型 | 后台任务降级 | 可选 |

内置服务商（`ProviderKind`）共 4 种：

| 服务商 | 默认 Base URL | 默认模型 | 是否需要 API Key |
| --- | --- | --- | --- |
| DeepSeek | `https://api.deepseek.com` | `deepseek-chat` | 需要 |
| 阿里百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` | `qwen3.7-plus` | 需要 |
| 家里电脑 Ollama | `http://192.168.1.100:11434/v1` | `qwen3:8b` | 不需要 |
| 自定义 OpenAI 兼容端点 | 空 | 空 | 需要 |

- 所有 API Key 与本地网关 Token 都保存在设置表中，并用 Android Keystore 的 AES-256-GCM 密钥加密（`data/.../secure/SecretStore.kt`）；**不要把密钥写进代码、截图或 Issue**。
- 请求直接由手机发往你配置的端点，不经过任何中转服务器。
- 生图 / 语音是可选的本地 AI 网关能力（DSHA Gateway：ComfyUI 生图、CosyVoice3 语音），在「设置 → 本地 AI 服务（生图 + 语音）」填写网关地址与 Token 即可，与聊天模型互不影响。
- 示例模式、Ollama 与本地网关不计入费用估算；DeepSeek / 阿里百炼的估算金额仅供参考，实际以服务商账单为准。

## 数据与隐私

聊天记录、记忆、日记、表情、备份与 API Key 全部保存在本机；只有组装好的提示词与最近对话会发送到**你自己配置**的模型服务。

- 数据库本身不加密，依赖 Android 应用沙箱；设备 root、调试版备份或恶意无障碍服务仍可能读取数据。
- 应用锁是应用内门禁，不是系统级安全容器；强杀或卸载不受 PIN 保护。
- 本地备份默认是明文 ZIP，建议存放在可信位置或启用口令加密。
- 换机恢复后，因 Keystore 密钥不随备份迁移，API Key 等设置可能需要重新填写；聊天、记忆、日记不受影响。

完整说明见 [PRIVACY.md](docs/PRIVACY.md) 与 [SECURITY.md](docs/SECURITY.md)。

## 常见问题

**完全免费吗？** App 本身免费且开源（MIT）。费用只来自你自己选择的模型服务商，App 内不做任何抽成。

**必须联网吗？** 聊天需要访问你配置的模型端点。用局域网内的 Ollama 时，可以完全不连公网。示例模式完全离线。

**我的聊天记录会被上传吗？** 不会上传到任何第三方服务器。只有组装好的提示词与最近对话会发给你填的那个端点。

**会偷偷收集统计或推送广告吗？** 不含统计、广告、远程配置 SDK。

**支持多设备同步吗？** 不支持，这是刻意的设计取舍。换机请用 App 内备份。

**为什么没有截图？** 截图容易带出真实聊天与 Key，仓库默认不附带。你可以在自己设备上截图后放到 `docs/images/`。

更多排错（签名冲突、语音不可用、收不到主动消息、生图无反应等）见 [SETUP.md](docs/SETUP.md#6-常见问题)。
