# 行为准则（CODE_OF_CONDUCT）

本文件改编自 [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)，并结合本项目场景做了精简。

## 我们的承诺

作为成员、贡献者和维护者，我们承诺让参与本项目的每个人都不受骚扰，无论其年龄、体型、可见或不可见的残障、族裔、性别认同与表达、经验水平、教育背景、社会经济状况、国籍、外貌、种族、宗教、性取向或技术选择。

我们承诺以建设性的方式行动与交流，共同营造开放、友好、可持续的社区。

## 期望行为

- 对他人保持同理心与善意。
- 尊重不同的观点、经验与使用场景。
- 给出具体、可执行的反馈，批评代码而不是攻击人。
- 承认错误，主动道歉，并从经验中学习。
- 优先考虑社区与用户的整体利益，而不只是个人偏好。
- 讨论敏感话题（亲密关系、心理健康、成人向陪伴设定）时保持克制，不主动展示令人不适的细节。

## 不可接受的行为

- 性化语言、图像或不受欢迎的性关注与示好。
- 钓鱼、侮辱、贬损、人身攻击或政治攻击。
- 公开或私下的骚扰、跟踪、威胁。
- 未经允许发布他人的私人信息（真实姓名、住址、账号、聊天记录、照片、API Key 等）。
- 在 Issue / PR 中粘贴真实密钥、完整聊天记录、备份文件或未脱敏截图。
- 其他在专业场合明显不当的行为。

## 执行责任

维护者有权删除、编辑或拒绝不符合本准则的评论、提交、代码、Issue 与其他贡献，并会在必要时说明理由。维护者应公平、一致地执行本准则，并对举报者的隐私负责。

## 适用范围

本准则适用于项目仓库、Issue、PR、Discussions、代码评审以及以项目名义参与的其他公开或私下场合。

## 举报与处理

- 请通过 **GitHub Issue** 联系维护者；如涉及隐私或安全，请避免公开细节，先发一个不含敏感信息的 Issue 说明「需要私下联系」。
- 安全漏洞请按 [SECURITY.md](SECURITY.md) 使用 GitHub Security Advisory，不要公开 Issue。
- 维护者会在合理时间内确认、评估并采取措施；必要时会与当事人沟通，或暂时 / 永久禁止参与。
- 举报应包含时间、地点（链接）、行为描述与可核实的证据；请勿传播无关的私人信息。

## 归属
