# 隐私说明（PRIVACY）

小鱼默认把所有内容留在这台设备上。它没有账号系统、没有云端同步、没有埋点，也不会把聊天记录上传到任何官方服务器。

## 1. 数据存在哪里

| 数据 | 存储位置 | 是否加密 |
| --- | --- | --- |
| 聊天、记忆、日记、心情、好感度、生活碎片、会话、草稿、请求快照、表情元数据 | 应用私有数据库 `xiaoyu.db`（Room，schema v6，17 张表） | 否，受 Android 应用沙箱保护 |
| API Key、本地网关 Token、全部设置项 | `settings` 表（单行 JSON） | **是**，使用 Android Keystore 中别名 `xiaoyu_settings_key` 的 AES-256-GCM 密钥整段加密 |
| 应用锁 PIN | `files/secure/app_lock.json` | **是**，PIN 先做 PBKDF2 哈希，再用 Keystore 密钥加密；**不进入备份** |
| 聊天背景 | 应用私有文件目录（压缩后保存） | 否，仅本机 |
| 表情图片 | `files/stickers/<packId>/` | 否，仅本机 |
| 人格头像 | `files/personas/<包名>/` | 否，仅本机 |
| 自定义提示词 | `files/prompts/`、`files/persona_prompts/<包名>/` | 否，仅本机 |
| 本地备份 | 应用外部目录 `backups/`，文件名 `xiaoyu-yyyyMMdd-HHmm.xiaoyu` | 可选口令加密（PBKDF2 + AES-GCM，文件头 `XYBK`） |
| Markdown 导出 | 公共下载目录 `Download/小鱼导出/` | 否，任何能读该目录的应用都可能读取 |
| 诊断快照 | 应用私有数据库 `request_snapshots`，最近 50 次 | 否，仅本机 |

系统自动备份已关闭（`android:allowBackup="false"`），因此 Android 不会把数据库或文件自动同步到云端。

## 2. 哪些数据会离开设备

只有在你**主动配置并使用**模型服务时，数据才会发往对应服务商：

| 接收方 | 发送内容 | 何时发送 |
| --- | --- | --- |
| 你配置的聊天模型 | 系统提示词（身份、风格、心情、好感度、生活碎片、记忆、事实卡、表情目录、本轮指令）+ 最近 24 条消息 + 本次输入 | 每次发消息 |
| 你配置的记忆模型 | 会话内容（提炼）、记忆片段（晋升）、日记素材、生活碎片素材 | 后台提炼、每晚清算、生成生活碎片 |
| 你配置的视觉模型 | 你选择的图片与描述指令 | 使用「看图」或表情自动打标时 |
| 你的本地 AI 网关 | 生图提示词、待朗读文本 | 主动点击生图 / 朗读时 |
| 你的 Ollama | 同「聊天模型」 | 选择 Ollama 并聊天时 |

- API Key 通过请求头发给对应服务商；请确认你信任该服务商的隐私政策与数据留存策略。
- 本地 AI 网关只接收生成所需的提示词或文本，不接收聊天历史；具体以网关自身的实现为准。
- 没有任何统计、崩溃上报、广告 SDK 或第三方分析服务。诊断信息只写入本机数据库。

## 3. 权限用途

| 权限 | 用途 | 触发时机 |
| --- | --- | --- |
| `INTERNET` | 访问你配置的模型服务、本地 AI 网关 | 聊天、后台任务、生图、朗读 |
| `ACCESS_NETWORK_STATE` | 判断是否有网络，避免无网时反复重试 | 请求前 |
| `POST_NOTIFICATIONS` | 主动消息、后台任务结果、备份、系统提醒 | Android 13+ 首次需要通知时请求 |
| `RECEIVE_BOOT_COMPLETED` | 开机后恢复闹钟与周期任务 | 开机 |
| `WAKE_LOCK` | 后台任务执行时短暂保持唤醒 | WorkManager / 闹钟 |
| `REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` | 引导用户关闭省电限制，减少主动消息延迟 | 用户主动点击「后台自检」相关入口 |
| `USE_BIOMETRIC` | 应用锁使用指纹 / 面容解锁 | 开启生物识别解锁时 |
| `SCHEDULE_EXACT_ALARM` | 早安 08:05、晚安 23:50、主动消息准点触发 | Android 12+ 需要时请求 |
| `WRITE_EXTERNAL_STORAGE`（仅 Android 9 及以下） | 把 Markdown 导出写入公共 Download 目录 | Android 10 以下导出时 |

App **不申请**：录音、相机、通讯录、定位、短信、电话、读取相册权限。选图使用系统 Photo Picker，App 只拿到你选中的那一张 / 那一批文件。

## 4. 导出与备份包含什么

### 4.1 本地备份 `.xiaoyu`

包含：

- 整个 `xiaoyu.db`（聊天、记忆、日记、情绪、好感度、生活碎片、表情元数据、设置表等）
- `files/prompts/` 下所有 `.md` 自定义提示词模板

不包含：

- 表情图片文件、生成图片、人格头像、语音缓存
- 应用锁 PIN 文件
- 聊天背景图
- 你导出到公共下载目录的 Markdown

说明：

- 备份默认为明文 ZIP；开启「用口令加密备份」后，整个包用 PBKDF2 派生密钥 + AES-GCM 加密，口令错误无法恢复。
- 备份位于应用专属外部目录（`getExternalFilesDir`），卸载 App 时系统通常会一并删除；请及时转存到可信位置。
- 恢复分「合并（保留现有聊天）」与「覆盖（重启后生效）」两种；覆盖会替换当前数据库。
- 设置表使用本机 Keystore 密钥加密。换机恢复后旧密钥不可用，API Key 等设置可能回退默认值，需要重新填写；聊天、记忆、日记不受影响。

### 4.2 Markdown 导出

- 会话导出：`Download/小鱼导出/chat-<会话标题>-<时间>.md`，隐藏消息不导出，撤回消息保留占位，表情写成 `[表情:名称]`，图片复制到同目录 `assets/images/`。
- 日记导出：`Download/小鱼导出/diary-<日期>.md`。
- 公共下载目录不受应用沙箱保护，任何具备存储读取能力的应用都可能读取；分享前请自行检查内容。

## 5. 删除数据的入口

| 想删除什么 | 操作路径 | 说明 |
| --- | --- | --- |
| 单条 / 多条聊天 | 聊天页长按消息 →「删除」或多选 →「删除」 | 软删除：只从对话里收起，数据库仍保留原文 |
| 刚发出的消息 | 长按自己的消息 →「撤回」 | 2 分钟内可撤回，界面显示「你撤回了一条消息」 |
| 某条记忆 | 「她的记忆」→ 短期记忆 / 长期卡片 →「删除」 | 短期记忆进入回收站；长期卡片直接删除 |
| 回收站记忆 | 「她的记忆」→ 回收站 →「彻底删除」 | 不可恢复；30 天后也会自动物理删除 |
| 误删的短期记忆 | 「她的记忆」→ 回收站 →「捡回来」 | 恢复短期记忆 |
| 表情包 / 单枚表情 | 「设置 → 表情包 → 管理表情包」→ 删除 | 图片文件与数据库记录一起删除，不可恢复 |
| 诊断数据 | 「设置 → 诊断 → 查看最近请求」→「清空」 | 删除最近 50 次请求快照与错误记录 |
| 聊天背景 | 「设置 → 聊天背景 → 恢复默认」 | 删除本机背景图引用并回到纯色 |
| 模型配置 / API Key | 「设置 → 模型」→ 编辑对应槽位 →「清除」 | 清空该槽位的 Key 与地址 |
| 应用锁 PIN | 「设置 → 隐私与安全」→「关闭」 | 删除 `app_lock.json` 并关闭锁定 |
| 全部数据 | 卸载 App，或在系统设置中「清除存储」 | 数据库、文件、备份目录（应用外部目录可能保留）一并清除 |

注意：备份恢复是整体替换或合并，不能用于单独删除某条数据；如需彻底清除，请在恢复后重新检查记忆与聊天。

## 6. 安全边界

- 数据库本身不加密，依赖 Android 应用沙箱与设备锁屏。设备已 root 或被物理取证时，数据库可能被读取。
- 设置表与 PIN 虽有 Keystore 加密，但在已解锁的设备上，拥有应用沙箱访问权限的恶意软件仍可能调用 Keystore 解密。
- 为支持局域网本地网关，App 开启了明文 HTTP（`usesCleartextTraffic="true"`）。请只在可信网络使用，公网端点请使用 HTTPS。
- 不要把 API Key、聊天记录、备份文件或诊断包发到公开 Issue、群聊或截图里。需要求助时请先脱敏。

## 7. 第三方组件

App 使用 Room、OkHttp、WorkManager、Hilt、Compose、Glance 等开源库；它们只在本机运行，不包含统计或广告 SDK。模型服务与本地 AI 网关是**你自己选择并配置**的第三方服务，其数据处理规则由对应服务商决定。
