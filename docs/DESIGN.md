# 设计规范（DESIGN）

小鱼的设计目标不是“功能齐全的聊天工具”，而是**一间深夜客厅**：光线柔和、信息克制、对话永远是主角。所有视觉选择都服务于“她像一个真实的人，而不是一个 AI 面板”。

## 1. 设计理念

| 原则 | 落地方式 |
| --- | --- |
| 对话优先 | 聊天页只保留顶栏、消息流、输入栏；设置、记忆、日记等入口收进菜单，不堆底部 Tab。 |
| 安静 | 背景与卡片使用低饱和青灰；语义色只用于状态提示，不大面积铺色。 |
| 真实感 | 她的一侧气泡固定白 / 深灰；长回复可分段发送；回复节奏可加入思考延迟与深夜犯困。 |
| 可读 | 正文 16sp、行高 24sp；全局字号四档可调；聊天背景支持暗化与模糊。 |
| 不喧宾夺主 | 动效短、幅度小，不使用弹跳、旋转、彩色渐变等强刺激效果。 |
| 可退出 | 应用锁、通知隐藏、本地备份、导出与“停用本地 AI”都放在显眼位置。 |

## 3. 气泡

气泡样式由 `BubbleTheme.kt` 定义，用户可在「设置 → 外观 → 我的气泡」切换。她的一侧不随主题变化：

| 样式 | 她的气泡（浅 / 深） | 我的气泡（浅） | 我的气泡（深） |
| --- | --- | --- | --- |
| 青灰（默认，`BRAND`） | `#FFFFFF` / `#2A2D32` | `#3E7C8C`，文字白色 | `#2C5B67`，文字 `#DCEEF2` |
| 薄荷（`MINT`） | 同上 | `#95EC69`，文字 `#16280F` | `#3F6B52`，文字 `#E2F3E8` |
| 暖橙（`WARM`） | 同上 | `#F2A65A`，文字 `#3A2410` | `#8A5A2E`，文字 `#FBE7D0` |

几何与排版：

| 项目 | 规范 |
| --- | --- |
| 圆角 | 常规 `18dp`；靠头像/自己一侧的下角收窄为 `4dp` |
| 内边距 | 水平 `14dp`、垂直 `10dp` |
| 最大宽度 | 屏幕宽度的 `78%`，且不超过 `420dp` |
| 行高 | 正文 `24sp`；动作描写（斜体）使用 `14sp / 21sp`，透明度 `0.8` |
| 动作描写 | 以不可见分隔符 `U+2063` 标记的动作描写，斜体显示，不进入正文样式 |
| 流式光标 | 未完成时在气泡末尾显示 `▍` |

## 4. 字体与圆角

### 4.1 字号

| 层级 | 字号 / 行高 | 用途 |
| --- | --- | --- |
| `displaySmall` | 32sp / 40sp Semibold | 引导页大标题 |
| `headlineMedium` | 26sp / 34sp Semibold | 页面主标题 |
| `titleLarge` | 22sp / 30sp Semibold | 大区块标题 |
| `titleMedium` | 17sp / 24sp Medium | 卡片标题 |
| `titleSmall` | 15sp / 21sp Medium | 次级标题 |
| `bodyLarge` | 16sp / 24sp | 聊天气泡正文 |
| `bodyMedium` | 14sp / 21sp | 说明文字 |
| `bodySmall` | 13sp / 19sp | 次级说明 |
| `labelMedium` | 12sp / 16sp | 标签、辅助信息 |

全局字号档位：`90% / 100% / 115% / 130%`。只缩放 Typography 的字号与行高，不放大 density，避免图标与间距一起变形。

| Token | 圆角 | 典型用途 |
| --- | --- | --- |
| extraSmall | 6dp | 小标签 |

| medium | 14dp | 图片、预览图 |
| large | 20dp | 大卡片 |
| extraLarge | 28dp | 大号容器 |
| 专用 | 18dp / 4dp | 消息气泡 |

## 5. 动效原则

| 场景 | 参数 | 说明 |
| --- | --- | --- |
| 页面切换 | 水平位移 `1/4` 屏 + 淡入，默认 tween | 方向随导航前进/返回变化，幅度小 |
| “正在输入” | 先显示状态，再按 ReplyPacer 延迟 | 默认关闭；开启后 10 秒 ~ 5 分钟随机 |
| 节奏强度 | `0.2 ~ 2.0` 倍 | 深夜 0–5 点 ×1.9，23 点 ×1.4，6–7 点 ×1.2；精力 <30 ×1.3；上限 15 分钟 |
| 深夜犯困 | 深夜且精力 <40，或 50% 概率 | 直接回一句困了，不发起模型请求 |
| 分段发送 | 每段之间 `600ms ± 300ms` | 只有开启分段发送时生效 |
| 按钮反馈 | 按下 `180ms`，抬起 `120ms` | 只做轻微缩放，不做回弹 |
| 表情面板 | 淡入 + 缩放 `140ms`，退出 `120ms` | 初始缩放 `0.6` |
| 错误提示条 | 进入 `260ms`、退出 `200ms` | 从底部滑入 `1/3` 高度 |
| 引导页小鱼 | 水平 5200ms、垂直 2100ms，往复线性 | 纯 Canvas 绘制，不引入图片资源 |

原则：**动效解释状态，而不是表演**。任何动画都不应阻塞输入、延迟消息落库或让用户等待。

## 6. 无障碍与深色模式

- **字号**：提供四档全局缩放；气泡、按钮与列表均使用 `sp`，不使用固定像素文字。
- **对比度**：深色主题正文使用 `#EDE5DE` 配 `#1A1D1F`；浅色正文 `#1C2426` 配白色，避免纯黑纯白硬对比。
- **聊天背景**：支持 `0 ~ 24dp` 模糊与 `0 ~ 80%` 暗化，确保气泡文字可读；模糊仅 Android 12+ 生效，低版本自动只暗化。
- **图标语义**：纯图标按钮提供 `contentDescription`（如「返回」「语音输入」「展开音色列表」）。
- **触控区域**：可点击元素保持至少 48dp 的触控区域，不把点击热区压到小于视觉图标。
- **通知隐私**：应用锁开启时，通知与锁屏只显示「小鱼发来一条消息」，正文不落到锁屏。
- **RTL**：`supportsRtl="true"`，布局使用 `start/end` 而非固定左右。
- **动态取色**：默认关闭；开启后仅影响 Material 主题色，不改变气泡语义与状态色含义。
- **减少刺激**：无自动播放音频、无闪烁、无循环彩色动画；语音需要用户主动点击播放。
